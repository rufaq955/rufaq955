# Rufaq Ullah

MSc Bioengineering student at Dalian University of Technology, conducting thesis
research at **BGI Shenzhen**. I work on single-cell and spatial transcriptomics —
building reproducible pipelines that turn raw sequencing output into clean,
analysis-ready objects.

My interest is in making single-cell workflows reproducible enough that a result
survives being re-run by someone else six months later.

---

### Research focus

- **Single-nucleus RNA-seq** — preprocessing, ambient RNA correction, doublet
  detection, QC, and cross-sample integration
- **Spatial transcriptomics** — spatial data handling and segmentation workflows
- **Disease models** — ALS, sarcopenia, FSHD, and DMD in human and murine tissue
- **Haematological malignancy** — AML

### Featured

**[snrna-preprocessing-qc](https://github.com/rufaq955/snrna-preprocessing-qc)**
A reproducible preprocessing and QC pipeline for 10x single-nucleus RNA-seq.
Ambient RNA removal with CellBender → doublet detection with DoubletFinder →
cell-level QC → hand-off to Scanpy or Seurat. Every threshold is a CLI
parameter, every step is resumable, and CI validates the code on each push.
